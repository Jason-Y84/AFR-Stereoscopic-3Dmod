# RCRA-Stereoscopic-3Dmod
Ratchet & Clank Rift Apart Stereoscopic 3D &amp; 6DOF Head Tracking Patch

### 🤝 Credits & Acknowledgments
Based on and built upon [BerZerker96's 6DOF Head Tracking Mods Hub](https://github.com/BerZerker96/6DOF-Head-Tracking-Mods-Hub).

 Installation
1. Extract `version.dll`  `3D-6DOF config.ini` and `RiftApart-HeadTracking.asi` into your game root directory (where `RiftApart.exe` is located).
2. Launch the game.

> 💡 **Optional (6DOF Head Tracking): If you want to use 6DOF head tracking, start “OpenTrack” (`UDP over network` -> `127.0.0.1:4242`) before launching the game.
